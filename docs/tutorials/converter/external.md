# Most updated data

Due to the success of multi-threading and connection to EIC, reconstruction codes are under active development in using the [`JANA2`](https://jeffersonlab.github.io/JANA2/#/) framework. 


To obtain data with the latest [`npy`](../pytorch/dataset.md#supported-data-layouts) format, follow the build and run instructions in [`nps_recon`](https://github.com/tck199732/test_jana2_nps).
