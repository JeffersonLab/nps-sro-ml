# Virtual Desktop Infrastructure

Virtual Desktop Infrastructure (VDI) provides a desktop environment that runs
on centrally managed servers instead of directly on your local computer. You
connect to the remote desktop over the network and interact with its
applications, files, and graphical interface as if they were running locally.

VDI can provide a consistent managed environment, simplify access to
organization-hosted resources, and allow the same desktop to be reached from
different devices. Its responsiveness depends on network quality, and files
should be saved only in locations designated as persistent storage.

For JLab access requirements, connection steps, and support information, see
[JLab Knowledge Base article KB0011328](https://jlab.servicenowservices.com/kb?id=kb_article_view&sysparm_article=KB0011328).
