# Data

The project starts from replayed or simulated ROOT files and converts them into
graph datasets for PyTorch.

- [Raw data](./raw.md) describes the source files, ROOT trees, branches, and
  flattened waveform or pulse encodings.
- [Training data](./training.md) lists the prepared dataset locations and
  documents the graph tensors produced by each converter.

The listed filesystem paths are available inside the Jefferson Lab network.
